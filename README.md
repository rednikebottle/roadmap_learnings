# Roadmap Learnings

This repo is where I document everything I learn from [roadmap.sh](https://roadmap.sh).

## Structure

The repo is split into multiple folders, one for each roadmap or topic I'm working through. Each folder holds:

- **Progress**: how far I've gotten through the roadmap
- **Notes**: what I've learned along the way
- **Projects & exercises**: the things I've built or done to practice

## Why

I want one place to track my progress, look back on what I've covered, and keep a record of my learning journey.
